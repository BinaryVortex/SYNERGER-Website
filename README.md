# SYNERGER Website

A modern, static website built for SYNERGER, a clean energy company promoting renewable energy solutions.

## About SYNERGER

SYNERGER is dedicated to advancing renewable energy technologies. Our mission is to provide sustainable and innovative energy solutions that contribute to a greener future. "Renewable Energy I'm A Big Fan!"

## Features

- **Home Page**: Introduction to SYNERGER and our mission.
- **About Us**: Learn more about the company and our team.
- **Products**: Explore our range of clean energy products and services.
- **Gallery**: Visual showcase of our projects and technologies.
- **Content Pages**: Detailed information on various energy topics like wind energy and geothermal.
- **User Profiles**: Personalized user experiences.
- **Feedback**: Collect user feedback and inquiries.
- **Checkout**: E-commerce functionality for products.
- **Contact**: Get in touch with us.

## Technologies Used

- **HTML**: Structure and content of the website.
- **CSS**: Styling and layout (including responsive design).
- **JavaScript**: Interactive elements and dynamic functionality.

## Getting Started

### Prerequisites

- A web browser to view the website.
- No server required; it's a static site.

### Running Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/BinaryVortex/SYNERGER-Website.git
   ```
2. Navigate to the project directory:
   ```bash
   cd SYNERGER-Website
   ```
3. Open `start.html` in your web browser to view the splash screen, which will redirect to the home page.

### Live Demo

The website is hosted on GitHub Pages: [SYNERGER Website](https://binaryvortex.github.io/SYNERGER-Website/)

## Project Structure

- `start.html`: Splash screen with logo and team credits.
- `home.html`: Main home page.
- Various HTML files for different sections (e.g., `aboutus.html`, `products.html`, `gallery.html`).
- CSS files for styling (e.g., `style.css`, `navbar.css`).
- JavaScript files for interactivity (e.g., `navbar.js`).
- Image directories (`images_Stu1`, `images_Stu2`, etc.) for assets.
- `final web.zip`: Archived version of the website.
